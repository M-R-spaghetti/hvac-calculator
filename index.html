Обчислені параметри стану—

L — фактична об’ємна витрата зовнішнього повітря на вході за t₁ та P; густина не фіксується на рівні 1,2 кг/м³. Витрату, приведену до стандартних умов, слід спочатку перерахувати. Пресети −22 °C / 80 % та +32 °C / 45 % — демонстраційні сценарії, не нормативні кліматичні дані; для конкретного об’єкта задайте обґрунтовані розрахункові параметри. Розрахункова модель за заданими формулами: G = Lρ₁ наближено приймається як витрата сухого повітря у балансах ентальпії та вологи. Конденсат ≈ G(d₁ − d₂) / 1000. Якщо під час охолодження RH₂ > 100 %, прийнято RH₂ = 95 % із перерахунком d₂. Вода: cₚ = 4,187 кДж/(кг·К), ρ = 1000 кг/м³; Δt = 20 К (80/60 °C) або 5 К (7/12 °C). Витрата води орієнтовна. За t₂ < 0 °C можливе обмерзання. На діаграмі показано координати d–t та схематичний вектор між кінцевими станами, а не траєкторію теплообміну в апараті.

Формули та припущення аеродинамічного розрахунку⌄
Переріз, швидкість та гідравлічний діаметрA = πD² / 4 або A = ab; v = L / (3600A)
Dₕ = D або Dₕ = 2ab / (a + b); Re = vDₕ / ν
Тертя · Дарсі–Вейсбах / Альтшульλ = 0,11 · (ε / Dₕ + 68 / Re)⁰·²⁵
R = (λ / Dₕ) · (ρv² / 2), Па/м
—

Усі розміри у формулах — у метрах. Для Re < 2300 використовується λ = 64/Re; для 2300–4000 — лінійна інтерполяція між ламінарним значенням при Re = 2300 та Альтшулем при Re = 4000. Для прямокутного каналу застосовано наближення через Dₕ, зокрема для ламінарного режиму; за співвідношення сторін понад 4:1 точність потребує окремої перевірки. R враховує лише тертя прямої ділянки, без місцевих опорів. Для v > 34 м/с модель нестисливого потоку потребує уточнення. Ряд круглих розмірів — за завданням; прямокутні — вибірка номінальних сторін EN 1505. Це експрес-підбір, відповідність усього проєкту ДБН не перевіряється.
