# Інженерний калькулятор ОВіК

Односторінковий калькулятор українською мовою. Усі розрахунки виконуються у браузері.

- Припливна установка: параметри вологого повітря, діаграма d–t, теплова або холодильна потужність, витрата води та конденсат.
- Повітропроводи: круглий і прямокутний переріз, швидкість, питомі втрати тиску та підбір розміру.
- Друк розрахунків або збереження у PDF через браузер.

## Запуск

Відкрийте `index.html` у браузері. Для завантаження Tailwind CSS через CDN потрібен інтернет; власні стилі та логіка розрахунків містяться у файлі.

Або запустіть локальний сервер у папці репозиторію:

```sh
python3 -m http.server 8765
```

Відкрийте http://localhost:8765.

Формули та прийняті припущення доступні у розділах методики під кожним розрахунком.
