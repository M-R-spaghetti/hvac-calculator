# Експрес-калькулятор ОВіК

Калькулятор типових розрахунків припливної установки: психрометрія d–t, теплова / холодильна потужність, витрата води та конденсат.
Друга вкладка підбирає круглий або прямокутний повітропровід за швидкістю та обчислює питомі втрати тиску на тертя.

[Відкрити калькулятор](https://m-r-spaghetti.github.io/hvac-calculator/) · [Код index.html](index.html)

![Припливна установка та діаграма d–t](assets/screenshot.png)

## Запуск

Відкрийте `index.html` у браузері. Файл містить усі стилі, скрипти та графіку Canvas; встановлення бібліотек, сервер і підключення до інтернету для розрахунків не потрібні. Зовнішні посилання у методиці відкриваються окремо та не використовуються для обчислень.

Кнопка **PDF / Друк** відкриває стандартний діалог браузера. Обидва розрахунки та формули включаються у друкований звіт.

## Перевірений приклад

Припливна установка: **L = 5000 м³/год**, t₁ = −22 °C, RH₁ = 80 %, t₂ = +20 °C, P = 101 325 Па. Теплоносій — вода 80/60 °C.

| Результат | Значення |
| --- | ---: |
| Густина повітря на вході ρ₁ | 1,405 кг/м³ |
| Масова витрата G | 7027 кг/год |
| Теплова потужність Q | 82,54 кВт |
| Орієнтовна витрата води | 3,55 м³/год |
| Швидкість у круглому каналі Ø500 мм при L = 5000 м³/год | 7,07 м/с |
| Втрати на тертя для цього каналу, повітря +20 °C | 0,986 Па/м |

Результати перевірено прямою підстановкою у наведені в інтерфейсі формули. Це перевірка реалізації розрахункової моделі, без експериментального підтвердження підбору обладнання.

## Умови та обмеження

- **У першій вкладці L задано за умов зовнішнього повітря на вході (t₁, P)**; G = Lρ₁, ρ₁ = P / [287,05(t₁ + 273,15)]. Це фактичні м³/год, без автоматичного приведення до стандартних умов або до ρ = 1,2 кг/м³.
- Пресети **−22 °C / 80 %** та **+32 °C / 45 %** — демонстраційні сценарії. Вони не заявляються як нормативні дані для Києва або іншого населеного пункту. Значення для конкретного об’єкта потрібно обґрунтувати окремо.
- Графік має координати **d–t** з кривими відносної вологості та схематичним вектором між станами; це не I–d діаграма.
- У балансах ентальпії та вологи G = Lρ₁ наближено приймається як витрата сухого повітря. Якщо під час охолодження розрахункова RH₂ перевищує 100 %, використовується спрощений кінцевий стан RH₂ = 95 % із перерахунком вологовмісту. Реальні характеристики охолоджувача та обмерзання не моделюються.
- Для витрати води прийнято ρ = 1000 кг/м³ і cₚ = 4,187 кДж/(кг·К); це орієнтовний баланс, без підбору теплообмінника за каталогом.
- У другій вкладці властивості повітря фіксовані для +20 °C та 101 325 Па. Розрахунок Дарсі–Вейсбаха / Альтшуля враховує лише пряму ділянку, без місцевих опорів; шорсткість — 0,1 мм. Прямокутний канал розраховується через гідравлічний діаметр.
- Діапазон 4–8 м/с — прийнятий критерій експрес-підбору для промислової вентиляції. Акустика, вся мережа та відповідність проєкту ДБН не перевіряються.

Облік місцевих опорів і довжини мережі, процеси зволоження та рекуперації. Наразі ці функції не реалізовані.
